Noto Sans KR — 출처 및 변환 절차
================================

원본 출처:
  https://github.com/google/fonts/tree/main/ofl/notosanskr
  (raw: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf)

확인일: 2026-07-19

이 저장소 경로에는 더 이상 별도의 정적(static) Regular/Bold TTF가 없고, 단일 가변
폰트(variable font) NotoSansKR[wght].ttf 1개만 존재함을 GitHub API로 실측 확인했다
(google/fonts가 이 패밀리를 정적 배포에서 가변 폰트로 전환한 것으로 보임).

fpdf2(및 상당수 PDF 라이브러리)는 가변 폰트의 축(axis) 인스턴싱을 지원하지 않아,
가변 폰트 파일을 그대로 등록하면 굵기(wght) 축과 무관하게 항상 기본 인스턴스로만
렌더링된다. 즉 "Bold"로 등록해도 실제로는 두께가 바뀌지 않는다.

따라서 fonttools(fpdf2의 의존성으로 이미 설치됨)의 varLib.instancer로 두 정적
인스턴스를 직접 생성했다:

  py -3 -m fontTools.varLib.instancer -o fonts/NotoSansKR-Regular.ttf <원본 가변 폰트> wght=400
  py -3 -m fontTools.varLib.instancer -o fonts/NotoSansKR-Bold.ttf    <원본 가변 폰트> wght=700

생성된 두 파일이 이 디렉터리의 NotoSansKR-Regular.ttf / NotoSansKR-Bold.ttf이며,
make_pdf.py가 그대로 로드해 사용한다. 원본 가변 폰트 파일 자체는 용량(약 10MB)
문제로 저장소에 포함하지 않았다 — 필요 시 위 URL에서 재다운로드해 동일 명령으로
재생성할 수 있다.

라이선스: SIL Open Font License 1.1 (OFL.txt 동봉). 인스턴스화는 폰트 소프트웨어의
수정(modification)에 해당하며 OFL 조건상 허용된다(예약 폰트 이름 미사용, 라이선스
동봉 조건을 그대로 유지).
